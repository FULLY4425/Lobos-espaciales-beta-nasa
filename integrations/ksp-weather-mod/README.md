# LobosWeather · mod experimental KSP 1.12.x

Código fuente sin DLL precompilada. Consulta [instalación, controles, validación y límites](../../docs/KSP_CLIMA.md).

`install-weather.cmd` compila con .NET Framework y bibliotecas de tu propio KSP, luego copia la DLL resultante a GameData/LobosWeather. Sin compilación correcta no instala. No se ha probado todavía contra una instalación real de KSP.

Dentro del juego: barra de mods o Alt izquierdo + W; activar entrenamiento. Las fuerzas necesitan una casilla adicional. Opcional: seguir el mapa mediante el conector local en 127.0.0.1:7173. No usa Internet ni claves de Supabase.
