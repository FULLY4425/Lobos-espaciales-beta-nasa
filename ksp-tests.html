Abrir formulario de GitHub ↗
  1. Revisa el texto y descarga los logs revisados.
  2. Abre GitHub e inicia sesión. Si el informe no aparece, pégalo en «Informe detallado».
  3. Arrastra los archivos a «Logs y evidencias adjuntas» y espera a que terminen de subir.
  4. Confirma la prueba real y publica. Podrás añadir comentarios, sugerencias y nuevas evidencias después.
